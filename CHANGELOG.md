# История изменений

## 0.6.0 — 2026-11-01

- переход графического интерфейса с PyQt5 на PyQt6;
- обновлённый desktop-интерфейс в стиле Nordic Utility;
- поддержка запуска из исходников на Windows, Linux и macOS;
- кроссплатформенное управление установкой и запуском Ollama;
- тесты транскрипции, Telegram Chat Export и Ollama;
- сборка релизных дистрибутивов Windows и Linux через GitHub Actions.

## 0.5.0 — 2026-08-08

- транскрипция аудио и видео через faster-whisper;
- Markdown и JSON с цельным текстом и тайм-кодами;
- обработчик Telegram Chat Export;
- PyQt5 GUI, две цветовые темы и drag-and-drop;
- кликабельные пути и открытие папки результата;
- интеграция с контекстным меню Проводника;
- конфигурация PyInstaller и установщик Inno Setup.
